# فاطمه.exe — Birthday Website

یک تبریک تولد تعاملی با حال‌وهوای برنامه‌نویسی.

## اجرا
فقط فایل `index.html` را با مرورگر باز کنید.

## شخصی‌سازی
در ابتدای فایل `script.js` این قسمت را تغییر دهید:

```js
const CONFIG = {
  name: "فاطمه رحیمی",
  firstName: "فاطمه",
  birthday: "۲۱ مرداد",
  accentColor: "#8b5cf6"
};
```

برای تغییر رنگ، مقدار `accentColor` را عوض کنید.

## ساختار
- `index.html` — ساختار صفحات
- `style.css` — ظاهر و انیمیشن‌ها
- `script.js` — منطق و تعاملات

نکته: فونت‌ها در CSS از Google Fonts لود می‌شوند؛ اگر اینترنت در دسترس نباشد، مرورگر از فونت‌های جایگزین استفاده می‌کند.
